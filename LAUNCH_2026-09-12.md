# Vengeance Reloaded launch candidate — 2026-09-12

Branch: `launch/2026-09-12`

## Integrated
- Modern 1.13-aligned NCTH, optics, recoil, lasers, movement tracking and related shooting fixes already inherited from the consolidated branch.
- Grenade/launcher CTH, Throwing-trait AP/range effects, water/smoke interactions and AI grenade handling.
- Aimed hand-grenade throws now charge aim AP through `CalcTotalAPsToAttack`.
- Shaped charges on door locks.
- Softer visibility-range overlays.
- Human-like tactical AI: self-preservation, fallback/disengagement/rout/rally, medics, smoke, suppression, mutual support, crossfire, movement safety and target allocation.
- 6–9 soldier fireteam cohesion, local alert/noise response, staged/proportional reinforcement waves and remnant absorption.
- Militia tactical parity and strategic retreat handling.
- Deidranna doctrine layer integrated on top of the newer fireteam AI without restoring obsolete global-response behaviour.
- Radio operator trait assignment priority and mod-aware artillery shell lookup.
- Symmetric downed-casualty system for player/enemy/militia human combatants, 2–5 full-turn rescue window, no deliberate finishing of downed casualties, first-aid stabilization.
- Stabilized casualties remain below the conscious-life threshold during tactical combat and cannot return to the fight.

## Deliberately not included in this launch candidate
- Person/corpse dragging/carrying. Current 1.13 implementation spans soldier-state/save layout, skill menu, movement/pathing/AP/noise and UI hooks; Vengeance contains none of that dependency set, so a rushed partial port is unsafe.
- Separate safe CAS/airstrike subsystem. Legacy air-raid code remains disabled; it has not been re-enabled as a shortcut.
- Equipment-upgrade shortcut/button: not verified/ported in this branch.
